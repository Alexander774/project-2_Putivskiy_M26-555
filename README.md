# Primitive DB

Учебная база данных на Python 3.12 с управлением таблицами и операциями CRUD. Схемы таблиц хранятся в `db_meta.json`, а записи — в отдельных файлах `data/<имя_таблицы>.json` в текущей рабочей директории.

## Установка и запуск

В каталоге репозитория:

```bash
uv sync
uv run database
```

Для сборки и проверки метаданных без публикации:

```bash
rm -rf dist
uv build
uvx twine check dist/*
uv tool install --force dist/*.whl
database
```

`uv tool install` устанавливает команду отдельно от окружения разработки. Чтобы применить изменения к уже установленной версии, установите новую сборку командой с `--force`.

## Управление таблицами

Поддерживаемые типы: `int`, `str`, `bool`. Поле `ID:int` добавляется автоматически; в `insert` вводить его не нужно.

| Команда | Операция |
| --- | --- |
| `create_table <имя> <столбец:тип> ...` | Создать таблицу |
| `list_tables` | Показать таблицы |
| `drop_table <имя>` | Удалить таблицу (с подтверждением) |
| `help` | Показать справку |
| `exit` | Завершить программу |

## CRUD-операции

| Команда | Операция |
| --- | --- |
| `insert into users values ("Sergei", 28, true)` | Добавить запись |
| `select from users` | Показать все записи |
| `select from users where age = 28` | Выбрать записи по условию |
| `update users set age = 29 where name = "Sergei"` | Изменить записи по условию |
| `delete from users where ID = 1` | Удалить записи (с подтверждением) |
| `info users` | Показать схему и количество записей |

Строки вводятся в одинарных или двойных кавычках. Целые числа и логические значения `true`/`false` — без кавычек. Все поля, кроме автоматически создаваемого `ID`, обязательны. Вывод `select` оформляется через PrettyTable.

Пример работы:

```text
>>>Введите команду: create_table users name:str age:int is_active:bool
Таблица "users" успешно создана со столбцами: ID:int, name:str, age:int, is_active:bool
>>>Введите команду: insert into users values ("Sergei", 28, true)
Функция insert выполнилась за 0.001 секунд
Запись с ID=1 успешно добавлена в таблицу "users".
>>>Введите команду: select from users where age = 28
Функция select выполнилась за 0.000 секунд
+----+--------+-----+-----------+
| ID |  name  | age | is_active |
+----+--------+-----+-----------+
| 1  | Sergei | 28  |    True   |
+----+--------+-----+-----------+
>>>Введите команду: delete from users where ID = 1
Вы уверены, что хотите выполнить "удаление записей"? [y/n]: n
Операция отменена.
>>>Введите команду: drop_table users
Вы уверены, что хотите выполнить "удаление таблицы"? [y/n]: y
Таблица "users" успешно удалена.
```

Время выполнения зависит от компьютера; в примере приведены условные значения.

## Декораторы и замыкание

`src/primitive_db/decorators.py` — основной модуль декораторов, устанавливаемый вместе с пакетом. `src/decorators.py` предоставляет те же функции для соответствия структуре задания.

- **`@handle_db_errors`** централизованно выводит сообщения об ошибках (`KeyError`, `ValueError`, `FileNotFoundError` и непредвиденных исключениях). При ошибке операция возвращает `None`, и командный цикл не сохраняет изменения.
- **`@confirm_action("удаление таблицы")`** и **`@confirm_action("удаление записей")`** требуют подтверждения `y`. Любой другой ответ отменяет операцию, не изменяя файлы данных.
- **`@log_time`** измеряет `insert` и `select` с помощью `time.monotonic()` и выводит время с точностью до тысячных секунды.
- **`create_cacher()`** возвращает функцию с собственным словарём в замыкании. `select` кэширует результаты по содержимому данных и условию. Если записи изменились, ключ кэша меняется; возвращаемые записи копируются, чтобы их нельзя было изменить через кэш.

Метаданные и пользовательские данные не включаются в Git. Если удалить таблицу, её JSON-файл также удаляется (после подтверждения).
